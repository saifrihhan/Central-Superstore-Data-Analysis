# Central Superstore Data Analysis & SQL Architecture

## Project Overview
This project focuses on processing, structuring, and analyzing sales and operational data for **Central Superstore**. It includes data staging, relational database setup, data cleaning, and executing 20+ advanced SQL queries to derive actionable business insights.

---

##  Tech Stack & Tools
* **Excel / CSV:** Raw and staging data storage.
* **SQL:** Database creation, data manipulation, advanced queries, CTEs, Views, and Stored Procedures.

---

## Project Structure
* `Central_Superstore.xlsx` & `central_superstore_staging.csv` – Raw and cleaned dataset files.
* `Main creation data importing.sql` – Database schema setup and data ingestion scripts.
* `Main sql queries and CTE.sql` – Analytical business queries using CTEs and advanced aggregations.
* `Main View and procedure.sql` – Database views for recurring reports and stored procedures for automated workflows.

---

## 💡 Key SQL Concepts Applied
* **Data Cleaning & Staging:** Transforming raw data into structured SQL tables.
* **CTEs (Common Table Expressions):** Modularizing complex logic for better readability and efficiency.
* **Views:** Creating pre-computed virtual tables for high-frequency business inquiries.
* **Stored Procedures:** Automating dynamic business reporting pipelines.
